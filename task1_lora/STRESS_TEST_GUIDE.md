# Task 1 challenge-set protocol

The recorded held-out set has 100/100 exact matches, so its failure list is empty. Do not manufacture failure examples. To probe limitations, create a separate `challenge_set.json` with cases not represented by the synthetic training generator: missing date, relative date ("next Friday"), ambiguous timezone, daylight-saving boundary, duplicate attendee, uncommon Unicode names, malformed time, conflicting dates, missing location, and request with no attendees. Run the same adapter inference/evaluation pipeline, save input/gold/raw output/parsed output/exact_match, and label results as a stress/challenge set rather than the original held-out test. Report up to three actual mismatches and diagnose them. If fewer than three occur, state that fewer than three were observed.
